# number comparison
-eq is ==
-ne is !=
-gt is >
-ge is >=
-lt is <
-le is <=



# string comparison

same string      --> =
different string --> !=
space string     --> -z
not space string --> -n


# logic operation
not  --> !
and  --> -a
or   --> -o
and  --> &&
or   --> ||


# file operation
-e  the file or directory is exist
-f  is a file
-d  is a directory
-r  have power to read
-w  have power to write
-x  have power to execution
-s  file is exist and is not space
